Key Takeaways

This tips dataset analysis explores tipping behavior across 244 restaurant bills — how day of week, party size, gender, and smoker status shape how much people tip.

  • Weekend checks run highest — Sunday averages $21.41, well above Friday’s $17.15 low
  • Tip % falls as tables grow: solo diners tip 21.7%, more than double the 14.2% at tables of 5
  • Bill and tip are strongly correlated (r = 0.676) — bigger checks mean bigger tips in dollar terms
  • Men place 64% of orders and spend more, yet women tip higher (16.6% vs 15.8%)
  • Smokers and non-smokers average similar tip %, but smokers vary 2.1× more widely
Source: Seaborn “tips” dataset · n = 244 Data Analysis & Visualization · Group Project

Fun Facts from the Data

  • 71% Tip
    One diner tipped $5.15 on a $7.25 bill — nearly doubling it. The most generous tip percentage in the entire dataset.
  • Friday Ghost Town
    Only 19 orders all Friday — Saturday had 87. The restaurant was 4.5x busier on Saturdays.

Python Analysis Code

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Load the tips dataset
tips = sns.load_dataset('tips')

# 1. Average Bill by Day
avg_bill = tips.groupby('day')['total_bill'].mean()
plt.figure(figsize=(8, 5))
sns.barplot(data=tips, x='day', y='total_bill',
            order=['Thur', 'Fri', 'Sat', 'Sun'],
            ci=None, palette='Blues_d')
plt.xlabel('Day of Week')
plt.ylabel('Average Bill ($)')
plt.title('Average Total Bill by Day')
plt.show()

# 2. Tip % by Party Size
tips['tip_pct'] = (tips['tip'] / tips['total_bill']) * 100
tip_by_size = tips.groupby('size')['tip_pct'].mean()
plt.figure(figsize=(8, 5))
plt.plot(tip_by_size.index, tip_by_size.values,
        marker='o', color='#ea580c', linewidth=2.5)
plt.fill_between(tip_by_size.index, tip_by_size.values,
                 alpha=0.1, color='#ea580c')
plt.xlabel('Party Size')
plt.ylabel('Average Tip %')
plt.title('Tip Percentage by Party Size')
plt.show()

# 3. Bill vs Tip (Scatter + Correlation)
from scipy import stats
r, p = stats.pearsonr(tips['total_bill'], tips['tip'])
print(f'Correlation: r = {r:.3f}, p = {p:.2e}')
plt.figure(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip',
                hue='time', alpha=0.6)
sns.regplot(data=tips, x='total_bill', y='tip',
            scatter=False, color='black',
            line_kws={'linestyle': '--', 'alpha': 0.4})
plt.xlabel('Total Bill ($)')
plt.ylabel('Tip Amount ($)')
plt.title(f'Bill vs Tip (r = {r:.3f})')
plt.show()

# 4. Gender: Spend vs Generosity
gender_stats = tips.groupby('sex').agg(
    count=('total_bill', 'count'),
    avg_bill=('total_bill', 'mean'),
    avg_tip_pct=('tip_pct', 'mean')
)
print(gender_stats)
plt.figure(figsize=(6, 6))
plt.pie(gender_stats['count'],
       labels=['Male', 'Female'],
       autopct='%1.1f%%',
       colors=['#2563eb', '#ea580c'],
       wedgeprops={'width': 0.4})
plt.title('Order Distribution by Gender')
plt.show()

# 5. Tip % Distribution by Smoker Status
plt.figure(figsize=(8, 5))
for label, group in tips.groupby('smoker'):
    plt.hist(group['tip_pct'], bins=15, alpha=0.6,
            label=label,
            color='#2563eb' if label == 'No' else '#ea580c')
plt.xlabel('Tip % of Bill')
plt.ylabel('Frequency')
plt.legend(title='Smoker')
plt.title('Tip % Distribution by Smoker Status')
plt.show()
